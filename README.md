# ⚔️ Dark Souls II - Fanpage & Hub

Um projeto web interativo desenvolvido para fãs de **Dark Souls II**, criado para consolidar conhecimentos em **HTML5** e **CSS3** (e futuramente JavaScript), além de compor meu portfólio de desenvolvimento web.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização visual, uso de variáveis CSS, Flexbox, Grid e responsividade.
- **Google Fonts**: Tipografia temática medieval (`Cinzel` e `Open Sans`).
- **Git & GitHub**: Controle de versão e hospedagem do código.

---
